# 🌡️ Temperature Converter

A lightweight, pure Vanilla JavaScript utility for converting temperature values between Celsius, Fahrenheit, and Kelvin, built as part of my [roadmap.sh](https://roadmap.sh/) JavaScript practice projects.

🔗 **Project Reference:** [roadmap.sh — Temperature Converter](https://roadmap.sh/projects/temperature-converter)

---

## ✨ Features

* **Multi-Unit Conversion:** Converts temperatures accurately between Celsius (°C), Fahrenheit (°F), and Kelvin (K).
* **Modular Function Design:** Clean, reusable helper functions separated by unit conversion logic.
* **Input Validation:** Handles invalid units or non-numeric inputs gracefully.
* **Zero Dependencies:** Pure JavaScript with no external libraries or UI boilerplate.

---

## 🛠️ Tech Stack

* **JavaScript (ES6+)** — Core conversion formulas, conditional routing, and input validation (`index.js`)
